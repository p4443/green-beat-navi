1. 制作体制の開示(AI 共同制作について)

本アプリは、製作者(人間)と GitHub Copilot(生成 AI によるコーディング支援)との共同制作です。透明性のため、役割分担と品質担保の方法を開示します。

担当役割
製作者(人間)要件の決定、方針の承認、AI 成果物の確認、クライアント対応、最終責任
GitHub Copilot(AI)設計・プログラム実装・テスト作成・文書作成の実務支援

品質の担保方法:AI の成果物は「動けばよし」とせず、①自動テスト 63 件 ②型検査・構文検査 ③実機ブラウザでの動作実証 ④GitHub 上の自動検査(脆弱性・秘密情報混入)⑤人間による承認、の多重チェックを全変更に適用しています(検証記録:GBN-TST-001)。

AI 活用の効果:通常 3〜5 ヶ月を要する規模の開発(2 章参照)を短期間・低コストで実現しました。使用技術はすべて公開されたオープンソースであり、AI 固有の権利問題が生じない構成です。
