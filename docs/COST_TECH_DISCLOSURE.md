## 1. 制作体制の開示(AI 共同制作について)

本アプリは、**製作者(人間)と GitHub Copilot(生成 AI によるコーディング支援)との共同制作**です。透明性のため、役割分担と品質担保の方法を開示します。

| 担当 | 役割 |
| :--- | :--- |
| 製作者(人間) | 要件の決定、方針の承認、AI 成果物の確認、クライアント対応、最終責任 |
| GitHub Copilot(AI) | 設計・プログラム実装・テスト作成・文書作成の実務支援 |

**品質の担保方法**:AI の成果物は「動けばよし」とせず、①自動テスト 63 件 ②型検査・構文検査 ③実機ブラウザでの動作実証(E2E) ④GitHub 上の自動検査(脆弱性・秘密情報混入)⑤人間による承認、の多重チェックを全変更に適用しています(検証記録:GBN-TST-001)。

**AI 活用の効果**:通常 3〜5 ヶ月を要する規模の開発(2 章参照)を短期間・低コストで実現しました。使用技術はすべて公開されたオープンソースであり、AI 固有の権利問題が生じない構成です。

## 3. 使用技術の仕様リスト(わかりやすい説明付き)

**すべて無料のオープンソース技術**で構成されており、ライセンス費用ゼロ・特定業者への依存(ロックイン)がありません。

| 区分 | 採用技術 | はたらき(平易な説明) | 費用 |
| :--- | :--- | :--- | :--- |
| プログラム言語 | TypeScript | JavaScript に「型」の安全性を足した言語。書き間違いを自動検出できる | 無料 |
| 画面の基盤 | Next.js 16 / React 19 | 世界で最も広く使われる Web アプリの土台。表示が速く、スマホ最適 | 無料 |
| アプリ化 | PWA(Serwist) | ブラウザから「ホーム画面に追加」でアプリとして起動。オフラインでも閲覧可 | 無料 |
| 地図 | MapLibre + OpenStreetMap | 無料のオープン地図。Google マップのような地図使用料が不要 | 無料 |
| QRコード | react-qr-code + 独自署名 | 掲示用 QR の生成。偽造防止の電子署名と当日期限は独自実装 | 無料 |
