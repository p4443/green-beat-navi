## 1. 完成済み機能のご確認(デモにてご覧ください)

### 来場者向け

- [ ] ホーム/会場マップ(コース・スポット表示)/タイムテーブル/出店一覧
- [ ] 匿名参加(氏名・連絡先の入力なし)→ QRスタンプラリー → 達成クーポン表示
- [ ] ホーム画面追加(アプリとして起動)・オフライン閲覧
- [ ] プライバシーノーティス常設(個人情報を収集しない設計の明示)

### 運営向け

- [ ] 運営画面からの告知・遅延・中止・混雑の配信(全端末の来場者画面へ自動反映)
- [ ] 運営ログイン(個人アカウント・パスワードなし)と4段階の権限(全体管理/プログラム/出店/閲覧)
- [ ] 操作記録(誰が・いつ・何を)の自動保存
- [ ] 掲示用QRの一括表示・印刷

### 不正・安全対策

- [ ] QRの偽造・複製対策(署名+当日限り有効。翌日は自動失効)
- [ ] SNSでQRが共有されても、現地に行かないとスタンプが揃わない仕組み(現在地・順序・移動時間のチェック。位置情報は端末内のみで照合し送信しません)
- [ ] 通信・画面の保護(常時HTTPS・セキュリティヘッダー・CSP適用)

### 品質・運用(数値は GBN-TST-001)

- [ ] アクセシビリティ自動監査:全10画面で違反ゼロ(WCAG AA 自動チェック)
- [ ] 負荷試験:同時接続 約3.4万人相当を処理(想定規模の十倍以上の余裕)・エラー0%
- [ ] 障害復旧:強制停止から約1秒で自動復旧
- [ ] 保守の無人化:プログラム部品の更新・安全検査・本番反映まで自動(人の作業は例外対応のみ)
